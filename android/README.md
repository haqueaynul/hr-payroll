# Native Android Studio Project: HRPayrollApp

This directory contains the native Android Studio project for HR Payroll built with Jetpack Compose & Material 3.

### How to Run in Android Studio:
1. Launch Android Studio (Hedgehog, Iguana, Jellyfish, or newer).
2. Choose "Open" and select the \`android\` directory.
3. Allow Gradle to sync.
4. Select an Android Emulator (API 26+) or a connected physical device.
5. Click the green **Run** button (Shift + F10).

### In-App 1-Click Download:
You can also download the complete ready-to-run bundled \`HRPayrollApp-Android-Studio.zip\` directly from the web app's **Mobile Apps (iOS & Android)** tab!
