# Native iOS Xcode Project: HRPayrollApp

This directory contains the native iOS Xcode project for HR Payroll.

### How to Run in Xcode:
1. Open \`ios/HRPayrollApp.xcodeproj\` in Xcode 15 or 16.
2. Select any iOS Simulator (e.g., iPhone 15 Pro, iPhone 16) or a connected physical iOS device.
3. Press **Cmd + R** to run.

### In-App 1-Click Download:
You can also download the complete ready-to-run bundled \`HRPayrollApp-iOS-Xcode.zip\` directly from the web app's **Mobile Apps (iOS & Android)** tab!
